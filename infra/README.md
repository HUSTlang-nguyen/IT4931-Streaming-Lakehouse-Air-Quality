# Hạ tầng Docker local

**Trạng thái ban đầu:** scaffold.

Đặt Docker Compose, Dockerfile và cấu hình Kafka/Spark/catalog/MinIO/Trino/Superset/PostgreSQL. Chưa có dịch vụ hoặc cổng được cấu hình. P1 phải chốt tương thích; P2 thêm health checks, volumes, resource limits và hướng dẫn PowerShell. Không dùng image latest, không xóa volume để che lỗi.
