# Bằng chứng và kết quả

**Trạng thái ban đầu:** scaffold.

Chưa có bằng chứng pipeline. Báo cáo nhỏ đã làm sạch trong reports/*.md hoặc reports/*.json được theo dõi Git. Raw logs, model, data, volume và file lớn không commit. Mỗi báo cáo ghi commit/dirty state, lệnh, dataset, config, kết quả và giới hạn; không bịa metrics.
